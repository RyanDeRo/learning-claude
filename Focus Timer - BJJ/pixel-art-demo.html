Technical Specifications

  • Base Canvas: 48×64 pixels (each avatar drawn at this size)
  • Display Size: 144×192 pixels (3× scale with nearest-neighbor interpolation)
  • Layer Count: 8 layers (body, hair_back, clothing_base, gear, face, hair_front, accessories, belt)
  • Color System: Indexed palette with runtime swapping for skin tones, hair colors, eye colors
  • Belt Colors: White → Blue → Purple → Brown → Black → Coral
  • Animation States: Idle (4f), Training (6f), Celebration (8f), Discouraged (4f), Rank-up (10f)
  • File Format: Transparent PNG, layer_{name}_{variant}_f{frame}.png
